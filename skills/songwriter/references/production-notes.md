# Production notes for humans

When the song is produced (also) by a band, producer or arranger rather than (only) by an AI. Production notes translate mood into actions.

## Structure
1. **Mood, specific:** not "vibey", but "night drive, melancholic, mid-tempo, hope only in the last chorus".
2. **Key data:** tempo, key (suggestion, depending on vocal range), time signature, target length.
3. **References with instructions:** 2–3 tracks, each with "take from this: …" (groove from A, vocal closeness from B, chorus width from C). References without instructions are worthless.
4. **Instrumentation:** core line-up, additional instruments from which section, what not at all.
5. **Section by section:** from structure plan and energy curve – where production pushes, where it pulls back, where there is silence.
6. **Vocals:** range, delivery, doubles, harmonies, ad-libs.
7. **Technical:** mix aesthetic (dry/roomy, modern/vintage), loudness target (streaming: about −14 LUFS integrated, −1 dBTP), formats (WAV 24-bit), stems wanted?

## Rules
- Don't break genre conventions without a reason.
- Concrete instructions instead of adjectives ("bass drops out in verse 1, comes back with eighths in the pre-chorus").
- Mark open decisions as questions, don't settle them silently.

## Format

```
Song: <title> – production notes
Mood: …
Key data: … BPM · key … · 4/4 · approx. 3:20
References:
  - <title – artist>: take …
Line-up: …
Sequence:
  Intro (0:00–0:08): …
  Verse 1: …
  Pre-chorus: …
  Chorus 1: …
  …
Vocals: …
Technical: …
Open questions: …
```
