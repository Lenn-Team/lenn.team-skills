# Lenn.Team Skills

Skills for Claude by [Lenn.Team](https://lenn.team). Each skill lives in its own folder under `skills/<name>/` with a `SKILL.md`.

| Skill | What it does |
|---|---|
| *coming soon:* `songwriter` – **Barde – Songwriter** | Writes song lyrics in the language you write in |

## Install

- **Claude Code:** ask Claude: *“Install the skill https://github.com/Lenn-Team/lenn.team-skills/tree/main/skills/&lt;name&gt;”*
- **Claude app:** download the skill folder as a ZIP and upload it under *Settings → Capabilities → Skills*.

## Conventions

- Public skills have an English, easy-to-find name (lowercase, hyphens) and English instructions; the result follows the user's language.
- The title in `SKILL.md` and the README may carry a picture name, e.g. “Barde – Songwriter”.
- Examples are our own texts, never lyrics or longer excerpts from other people's work.
